<tr>
<td><strong>DESARROLLO</strong></td>
</tr>
<tr>
<td><ul>
<li><p><strong>Introducción</strong></p></li>
<li><p>Los pacientes con enfermedad traumática presentan una elevada
incidencia de shock traumático, siendo la hemorragia una de las
principales causas subyacentes. Esta situación clínica crítica exige una
rápida respuesta, incluyendo la transfusión de hemocomponentes y
hemoderivados adaptados a las necesidades individuales del paciente. En
escenarios de sangrado masivo, puede ser necesario activar el Protocolo
de Hemorragia Masiva (PHM), lo que implica una movilización urgente de
recursos humanos y materiales.</p></li>
<li><p>Una adecuada activación de los recursos disponibles incluye no
solo la correcta solicitud de hemocomponentes, sino también su
administración oportuna mediante dispositivos como el infusor rápido con
calentador. Además, el uso precoz de concentrados de hematíes
compatibles del primer paquete transfusional permite iniciar una
reanimación hemostática eficaz, mientras se organiza el resto del
soporte transfusional.</p></li>
<li><p>La identificación precoz de la mejoría clínica del paciente es
esencial para valorar la desactivación del protocolo, evitando así el
uso innecesario de productos sanguíneos. En este contexto, cobra
especial importancia minimizar el desperdicio, asegurar la trazabilidad
y mantener los requisitos de conservación de cada componente. Una
devolución óptima de los hemocomponentes no utilizados debe realizarse
de forma coordinada con el Banco de Sangre del centro, respetando los
tiempos y condiciones de conservación, para preservar la seguridad del
paciente y la eficiencia del sistema transfusional.</p></li>
<li><p><strong>Solicitud de componentes sanguíneos</strong></p></li>
<li><p><strong>Realización de solicitud según situación
clínica</strong></p></li>
</ul>
<p>Se realizará la petición de los pacientes de la atención inicial
según situación clínica:</p>
<ul>
<li><p><em><u>Paciente estable</u></em>: Urgente en 10-15
minutos</p></li>
<li><p><em><u>Pacientes inestable con activación de PHM
prehospitaria:</u></em> Extrema urgencia (uso de sangre de la nevera de
la Unidad con comunicación a Banco de Sangre)</p></li>
<li><p><em><u>Paciente estable no traumático con bajo riesgo de
sangrado:</u></em> Urgente en 90 minutos con estudio de anticuerpos
(posteriormente, se enviará un tubo negro por parte de Banco de Sangre
para confirmación de grupo sanguíneo)</p></li>
<li><p><strong>Extracción y envió de muestras</strong></p></li>
</ul>
<p><img src="/matriz/media/transfusion_hemocomponentes_image2.png"
style="width:6.57986in;height:2.23264in" /></p>
<p><img src="/matriz/media/transfusion_hemocomponentes_image3.png"
style="width:6.57986in;height:3.42945in" /></p>
<ul>
<li><p><strong>Activación del PHM</strong></p></li>
</ul>
<p>La activación del Protocolo de Hemorragia Masiva será responsabilidad
del líder del equipo de atención inicial al trauma, y se llevará a cabo
en cualquiera de las siguientes situaciones:</p>
<ul>
<li><p>Tras recibir el preaviso prehospitalario, cuando la información
aportada indique una hemorragia potencialmente masiva.</p></li>
<li><p>Durante la valoración inicial hospitalaria, ante la
identificación de sangrado activo, o inestabilidad
hemodinámica.</p></li>
</ul>
<p>La activación se efectuará mediante la TCAE responsable del ingreso,
quien realizará la llamada directa al Banco de Sangre (teléfono:
68051)</p>
<p><strong>Antes de iniciar la administración de hemoderivados, y una
vez canalizado el catéter venoso de alto flujo o introducto</strong>r,
deberá obtenerse muestra sanguínea priorizando:</p>
<ul>
<li><p>Tubo de hemograma y piloto de sangre para pruebas
cruzadas.</p></li>
<li><p>Doble tubo de coagulación destinado a la realización del test
viscoelástico (Quantra), con el fin de orientar el tratamiento
hemostático dirigido.</p></li>
</ul>
<p>Se administrarán los componentes sanguíneos según el algoritmo del
PHM utilizando el primer paquete que se encuentra en la Unidad. Se
realizará la dispensacion mediante el sistema SADME sin orden (Ver
Imagen 1)</p>
<p>El uso de los concentrados dependerá de dos situaciones: mujer en
edad fértil y situación de extrema urgencia (paciente con identificación
mediante Rh)</p>
<ul>
<li><p>En la nevera de UCITE estarán separados 4 concentrados O positivo
en la balda <strong>AZUL</strong> y 2 concentrados O negativos en la
balda <strong>VERDE</strong>. Mantener los concentrados de hematíes en
posición vertical. (Ver imagen 2)</p></li>
<li><p>No usar como sangre para transfusión de rutina.</p></li>
<li><p>USO como a continuación:</p>
<ul>
<li><p>Mujer en edad fértil iniciamos con 0 – con dos concentrados y si
continuamos con PHM continuamos con los 4 de 0+</p></li>
<li><p>Varón iniciamos la transfusión con 0+ 4 concentrados y si
continua mal finalizamos el paquete con los 2 0-.</p></li>
</ul></li>
</ul>

<ul>
<li><p><strong>Administración de hemocomponentes</strong></p></li>
</ul>
<p>Los componentes sanguíneos se administrarán a través de un catéter
venoso central tipo introductor de alto flujo, disponible desde el
momento de la activación del PHM.</p>
<p>Se recomienda emplear un infusor rápido con sistema de calentamiento
para la administración de concentrados de hematíes y plasma garantizando
una adecuada velocidad de infusión y evitando la hipotermia.</p>
<p>⚠️ <strong>Excepción:</strong> las <strong>plaquetas NO deben
administrarse mediante infusor rápido</strong>, dado el riesgo de
<strong>precipitación, agregación y lisis celular</strong>. En su lugar,
deben infundirse por gravedad.</p>
<p>Se debe realizar el registro de los hemocomponentes mediante el
dispositivo de HEMOCOD al finalizar la atención inicial siguiendo los
siguientes pasos:</p>
<p><img src="/matriz/media/transfusion_hemocomponentes_image6.png"
style="width:4.10184in;height:3.09662in" /></p>
<ul>
<li><p><strong>Desactivación del PHM y devolución de componentes
sanguíneos</strong></p></li>
</ul>
<p>La desactivación del PHM debe realizarse de forma precoz y coordinada
tan pronto como la situación clínica lo permita, con el objetivo de
evitar la sobretransfusión y minimizar el desperdicio de
hemoderivados.</p>
<p>La finalización del protocolo se valorará cuando se cumplan las
siguientes condiciones clínicas y analíticas:</p>
<ol type="1">
<li><p>Control efectivo del foco de sangrado.</p></li>
<li><p>Estabilidad hemodinámica mantenida (sin signos de
shock).</p></li>
<li><p>Reducción o suspensión progresiva del soporte
vasoactivo.</p></li>
<li><p>Disminución significativa del ritmo de infusión a través del
sistema de infusión rápida.</p></li>
<li><p>Corrección documentada de la coagulopatía<strong>,</strong>
evidenciada por pruebas convencionales o viscoelásticas.</p></li>
</ol>
<p>Una vez confirmado el cumplimiento de estos criterios, el líder del
equipo asistencial comunicará formalmente la desactivación del PHM.
Posteriormente, se procederá a la devolución de los componentes
sanguíneos no utilizados, respetando las condiciones específicas de
conservación, trazabilidad y tiempo de viabilidad establecidas para cada
producto. (Anexo 2)</p></td>

<script>
  (() => {
    const lightbox = document.querySelector('.image-lightbox');
    if (!lightbox || typeof lightbox.showModal !== 'function') return;

    const enlargedImage = lightbox.querySelector('.image-lightbox__image');
    const closeButton = lightbox.querySelector('.image-lightbox__close');

    document.querySelectorAll(
      'img[src^="/matriz/media/"]:not(.image-lightbox__image)'
    ).forEach((image) => {
      image.classList.add('image-lightbox-trigger');
      image.tabIndex = 0;
      image.setAttribute('role', 'button');
      image.setAttribute('aria-label',
        image.alt ? `Ampliar imagen: ${image.alt}` : 'Ampliar imagen');

      const openImage = () => {
        enlargedImage.src = image.currentSrc || image.src;
        enlargedImage.alt = image.alt || '';
        lightbox.showModal();
      };

      image.addEventListener('click', openImage);
      image.addEventListener('keydown', (event) => {
        if (event.key === 'Enter' || event.key === ' ') {
          event.preventDefault();
          openImage();
        }
      });
    });

    closeButton.addEventListener('click', () => lightbox.close());
    enlargedImage.addEventListener('click', () => lightbox.close());
    lightbox.addEventListener('click', (event) => {
      if (event.target === lightbox ||
          event.target.classList.contains('image-lightbox__content')) {
        lightbox.close();
      }
    });
  })();
</script>
